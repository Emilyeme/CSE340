The loop over organizations demonstrates how data flows from your server into the template: each organization’s logo, name, and contact email are rendered dynamically.

Notice how <%= organization.logo_filename %> and <%= organization.name %> are escaped, which protects against malicious input, while the img tag uses those values to build the HTML.

This is exactly how client-side rendering with EJS ties the whole pipeline together: the server passes data into res.render(), and the template engine transforms it into HTML for the browser.
