Topic 1: Handling Form Submissions
Please paste the code from your processNewProjectForm function in src/controllers/projects.js so we can discuss how your application receives form data and passes it to the model.
const processNewProjectForm = async (req, res) => { const errors = validationResult(req); if (!errors.isEmpty()) { errors.array().forEach((error) => { req.flash('error', error.msg); }); return res.redirect('/new-project'); } const { title, description, location, date, organizationId } = req.body; try { const newProjectId = await createProject( title, description, location, date, organizationId ); req.flash('success', 'New service project created successfully!'); res.redirect(/project/${newProjectId}); } catch (error) { console.error('Error creating new project:', error); req.flash('error', 'There was an error creating the service project.'); res.redirect('/new-project'); } };
Excellent, Emily. This function handles the submission in a clear sequence: it checks validation results, reads the submitted values from req.body, passes those values to createProject(), shows a flash message, and redirects to the new project’s details page. The try/catch also gives your application a way to handle database errors without leaving the user on a broken page.
What is the purpose of req.body in this function, and why do you pass those values to createProject() rather than putting the database query directly inside the controller?
req.body contains users data , we pass values to createProject() because it is a function that know ho to talk to the database
Exactly, Emily. ?? You’ve identified an important MVC principle: the controller handles the request and coordinates the work, while the model contains the database logic. That separation makes the code easier to organize and maintain.

Nice work, Emily. ?? This is a good example of an update form. The EJS expressions such as <%= project.title %> insert the existing project values into the form, while the selected expression makes the project's current organization appear selected.
