Great. This is a good example for Registration and Password Hashing.
Your code first gets the user's name, email, and password from the registration form. Then you generate a salt and use bcrypt.hash() to create a password hash before calling createUser(). That means the plain password is not what your application sends to the database.
I also notice your comment makes the security purpose clear:
// Hash the password before storing it
const salt = await bcrypt.genSalt(10);
const passwordHash = await bcrypt.hash(password, salt);
The passwordHash is then passed to your database function:
const userId = await createUser(name, email, passwordHash);
This is important because even if someone were able to view the database, they would not simply see the user's original password.
